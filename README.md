An automation pipeline that takes messy, multi-source sales data, cleans and
restructures it without manual effort, computes the KPIs a business actually
needs, and notifies the team automatically the moment a new run is ready —
built to show how I approach operational data problems end to end, not just
the analysis step.

> **For anyone reviewing this as a portfolio piece:** every number below is a
> real output from running this code, not written by hand. All data is
> synthetically generated for demonstration (see *Data note* below) — the
> automation and cleaning logic is what's on display, and it's built to work
> on any dataset with a similar shape.

---

## The problem

Teams that pull sales data from more than one system — a CRM, a point-of-sale
platform, a wholesale partner's SFTP feed — almost always deal with the same
pain: duplicate records, inconsistent date/currency formats, and missing
fields that someone has to clean by hand before any report can be trusted.
That manual cleanup is slow, error-prone, and doesn't scale as data volume
grows.

## What this does about it

1. **Ingests** raw exports from three separate source systems.
2. **Cleans and restructures** them automatically — deduplicates, standardizes
   formats, and fixes or flags missing values, logging every decision so the
   output stays auditable rather than a black box.
3. **Computes** the KPIs a stakeholder would actually ask for — revenue,
   customer concentration, order trends — and writes a formatted report.
4. **Notifies** the team automatically through a live Zapier integration the
   moment a new run completes, with zero manual checking.

```
 3 raw source exports (CRM · POS · SFTP)
            │
            ▼
 Python cleaning engine
   • parses inconsistent dates & currency formats
   • removes cross-system duplicates
   • fixes/flags missing values — never silently drops data
   • restructures everything into a clean, analysis-ready dataset
            │
            ▼
 KPI + report generation
   • revenue, customer concentration, order trends
   • formatted Excel report
            │
            ▼
 Google Sheets run log
            │
            ▼
 Zapier — detects the new run and sends an automatic
 email notification with the results
```

## Why this matters for a role, not just as a script

This mirrors a common ask in operations/analytics roles: read and modify
Python for reporting, use Advanced Excel for data analysis, and use no-code
tools like Zapier to automate workflows and integrate systems. This project
demonstrates all three working together on one problem, end to end, rather
than in isolation.

## How to run it

```bash
pip install -r requirements.txt
python scripts/01_generate_raw_data.py       # generates raw/messy source files
python scripts/02_clean_and_restructure.py   # cleans + builds the clean dataset
python scripts/03_generate_report.py         # computes KPIs + writes the report
```

Outputs land in `outputs/sales_report.xlsx` and `data/processed/`. Every
script is deterministic (seeded), so re-running it reproduces the numbers
above.

## Connecting the Zapier layer yourself

1. Create a Google Sheet named `automation_run_log` with columns:
   `run_timestamp`, `raw_rows_ingested`, `clean_rows_written`,
   `records_auto_cleaned`, `total_revenue`, `top10_customer_share`,
   `est_manual_hours_saved`, `status`.
2. After each run, append `outputs/zapier_trigger_row.csv` as a new row.
3. In Zapier: **Trigger** → Google Sheets → *New Spreadsheet Row* →
   `automation_run_log`. **Action** → Gmail → *Send Email*, composed using
   the trigger's fields.
